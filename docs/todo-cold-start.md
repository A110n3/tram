# 任务清单：修复"首次使用需加载模型，浮窗一直提示加载中"

> 背景：2026-08-18 用户报告 OCR 识图 / 划词翻译第一次触发时，后端本地模型
> 未加载，浮窗提示"（等待后端响应，可能在加载模型）"后长时间不变，用户以为
> 卡死，需重新识图/取词才能用。会话额度有限，每完成一步在下方打勾并记录。

## 诊断结论（已完成，2026-08-18）

- [x] 纯后端管线无 bug：`tools/repro_slow_first_request.py` hold /
      headers_then_hold 模式（延迟 15s）均正常拿到结果。
- [x] 真实后端为 Lemonade Server（RyzenAI，localhost:13305）。复现：
      `curl -X POST /api/v1/unload` 卸载模型后走应用真实管线
      （`tools/repro_cold_start_real.py`）：
  - 模型未加载时首个请求 **阻塞到加载完成才返回**（实测 TTFB≈41s，
    NPU 首次冷编译可能数分钟），期间无任何字节 -> 浮窗 8s 慢提示出现
    后一直停留 -> 与用户"卡死"感受一致。加载完成后本次请求其实会成功，
    但用户早已重新触发（此时模型已热，立刻成功）。
  - 另一种服务器状态下未加载直接返回 500（1ms），现有重试逻辑可自愈。
  - 次要发现：Qwen3 为思考模型，加载后首批 delta 是 `reasoning_content`
    （我们已正确忽略只取 `content`）；但若思考耗尽 `max_tokens`，
    翻译会"成功"但结果为空字符串 -> 浮窗被清空，无任何提示。
- [x] 根因定性：不是管线 bug，是**首个请求承担了模型加载成本** + 
      **空结果无守卫**。修复方向：启动预热 + 空结果守卫。
